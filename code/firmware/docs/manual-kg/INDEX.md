## 这个图谱怎么用

扩展项目功能时，按以下顺序查阅：

1. **先看板子有什么** → [`hardware/board-resources.md`](hardware/board-resources.md)：板载外设、芯片型号、引脚分配、跳线。
2. **再确认引脚是否被占用** → [`hardware/pin-map.md`](hardware/pin-map.md)：外设↔引脚↔当前固件占用情况。
3. **找对应例程** → [`examples/`](examples/)：77 个官方例程的结构化条目，每条含引脚、API、初始化步骤、常见坑、原手册页码。
4. **需要原文细节** → [`_text/`](_text/)：第 1/5/7 章去页眉页脚的全文，按 `<!-- PDF p.N -->` 标注页码，可直接 grep。
5. **看当前固件实现了什么** → [`firmware-map.md`](firmware-map.md)：手册条目 ↔ 本项目 `bsp_*.c` 模块双向链接。

> 页码约定：文中所有 `p.N` 均指 **PDF 物理页**（= 手册印刷页码，两者一致，因为 PDF 第 21 页 = 手册第 21 页）。
