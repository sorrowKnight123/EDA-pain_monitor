# 神舟III号开发板资源总览

> 手册：第 1 章 硬件篇，p.21-28（1.1 简介）
> 用途：扩展功能前，先在这里确认板子**本身**提供了什么。

## 处理器

| 项目 | 参数 |
|------|------|
| 型号 | **STM32F103ZET6**（F103 系列最高配置） |
| 内核 | Cortex-M3，32 位 |
| 主频 | 72 MHz |
| 封装 | LQFP144 |
| 片内 Flash | 512 KB |
| 片内 SRAM | 64 KB |
| 特有外设 | 相比同系列增加 ETM、FSMC 总线、SDIO 接口、2 个 I2S 接口 |

板子尺寸 110×150 mm。**除晶振占用的 IO 外，其余所有 IO 全部引出**（双排插针），扩展方便。

## 板载资源清单（p.22）

| 类别 | 资源 |
|------|------|
| 存储 | 1G bit Nand Flash（FSMC）、16M bit Nor Flash（FSMC，最大可换 128M bit）、4M bit SRAM（FSMC，手册 1.2.7 亦称 8M bit，以实物丝印为准）、2M bit I2C EEPROM（24C02）、16M bit SPI Flash（W25X16） |
| 显示 | 1 个标准 2.8/3.2 寸 LCD 接口（320×240，26 万色，支持触摸） |
| 音频 | 专用 I2S 音频 DA 芯片（PCM1770）、音频接口、收音机模块（TEA5767） |
| 通信 | 2 路串口（DB9 公头）、1 路 RS-485、1 路 CAN（VP230 收发器）、1 路 10M 以太网（ENC28J60） |
| 存储卡 | 1 个 SD 卡接口（SDIO 模式） |
| 无线 | 2.4G 无线模块接口（nRF24L01+）、315M 无线模块接口 |
| 人机 | 4 个状态 LED（DS1~DS4 绿）、1 个电源指示灯、1 个复位按钮、4 个功能按钮（含 WAKEUP/TAMPER） |
| 调试 | 标准 JTAG/SWD 接口（20 针，支持 JLink 供电） |
| 电源 | 5V 外部电源输入（内正外负）、电源开关、USB Slave（可供电） |
| 模拟 | 1 路电位器（接 ADC，用于 AD 实验）、预留 AD/DA/PWM 接口 |
| 其他 | 启动模式选择配置接口、RTC 后备电池座（CR1220）、预留 AD/DC/PWM 接口 |

## 关键跳线

### 启动模式（BOOT）— J9/J10（p.26）

| BOOT1 (J9) | BOOT0 (J10) | 功能 |
|-----------|-------------|------|
| ANY | 2-3 | User Boot（默认，从内部 Flash 启动） |
| 2-3 | 1-2 | System Boot（从系统存储器启动，用于串口 ISP 下载） |
| 1-2 | 1-2 | SRAM Boot |

### RS-232 / RS-485 选择（串口2）— J12/J14（p.28, p.41）

| J12 | J14 | 功能 |
|-----|-----|------|
| 1-2 | 1-2 | 串口2 = RS-485 接口 |
| 2-3 | 2-3 | 串口2 = RS-232 接口 |

> 串口2 作为 RS-485 使用时，板上默认装了 120Ω 终端匹配电阻 R82，按实际应用决定是否保留。

### RTC 电池 — J11（p.31）

- 装了电池：J11 的 2-3 脚短接，VBAT 由电池供电。
- 未装电池：J11 的 1-2 脚短接，VBAT 由 +3.3V 系统电源供电。

## 供电方式（p.36）

| 方式 | 说明 |
|------|------|
| USB 接口供电 | 最大 500 mA（带 500mA 自恢复保险丝） |
| 外部直流 5V | DC 电源座，内正外负 |
| JLink V8 供电 | 支持 5V 和 3.3V 两种 |

电源转换：ASM1117-3.3V 把 5V 转 3.3V。电源开关 CON1 控制 3.3V 通断。

## 外接模块支持清单（1.3 节，p.46-47）

可选配件：DS18B20 温度传感器、DHT11 温湿度传感器、2.4G 无线模块、315M 无线收发、三轴加速度模块、MP3 播放模块、2.8/3.2/4.3/7 寸液晶屏模块。
