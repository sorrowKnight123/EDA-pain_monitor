# 例程条目模板（子代理统一遵守）

每个例程条目必须**忠实于手册原文**，不得杜撰引脚/API/参数。信息不足的字段写"手册未明确"，不要编造。

```markdown
### 7.N 例程名（p.起始-结束）

| 字段 | 内容 |
|------|------|
| 外设/模块 | 涉及的外设，如 ADC1 / USART1 / FSMC |
| 接口/总线 | 如 APB2、FSMC Bank1 NE4、软件模拟 I2C |
| 关键引脚 | 从原文提取，如 PF6~PF9；无则写"未明确" |
| 时钟使能 | 从原文提取，如 RCC_APB2Periph_GPIOF |
| 关键 API / 寄存器 | 库函数名或寄存器名，逗号分隔 |
| 初始化步骤 | 手册列出的编号步骤，压缩成 3-6 条 |
| 常见坑 / 注意 | 手册明确警告的点；无则写"无特别说明" |
| 依赖前置 | 需要先跑通哪个例程，或需要什么硬件/跳线 |

**一句话作用**：……
```

## 提取规则

1. **页码**：用 `<!-- PDF p.N -->` 注释定位；条目头部写 `p.起-止`（该例程 TOC 的 start-end）。
2. **引脚**：只写手册明说的（"PC3 管脚""PF6~PF9"），不要推断。
3. **API**：优先 `SZ_STM32_*`、`GPIO_*`、`USART_*`、`ADC_*`、`FSMC_*`、`SPI_*`、`TIM_*`、`RTC_*`、`I2C_*`、`CAN_*`、`DMA_*`、`FLASH_*`、`PWR_*`、`IWDG_*`、`WWDG_*`、`CRC_*`、`PVD_*` 等库函数名；寄存器名如 `ADC_CR1`、`USART_BRR`、`GPIOx_CRL`。
4. **初始化步骤**：手册常以"1）2）3）"列出，直接压缩。
5. **坑**：如"ADC 输入时钟不得超过 14MHz""W25X16 与网口共用 SPI1 不可同时使能 CS"这类。
6. 每个文件顶部写标题 `# 第7章 例程：<分类名>`，然后按例程号顺序排列。

## 输出

一个分类一个文件，写到 `docs/manual-kg/examples/<NN>-<slug>.md`，并在 `examples/README.md` 的表格中登记（由主代理统一汇总，子代理不必改 README）。
