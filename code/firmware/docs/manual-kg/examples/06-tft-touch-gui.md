# 第7章 例程：TFT 液晶屏显示 / 触摸屏 / GUI

> 手册 p.602-672

> 说明：7.37~7.54 是 7.36 之后的递进短例程，硬件设计多为"硬件设计同上"，故公共配置统一见 7.36，各条只记录该例程特有内容。7.36 为本章的配置基础（FSMC 驱动 LCD + 触摸屏）。

### 7.36 TFT彩色液晶屏只显示红色（p.602-619）

| 字段 | 内容 |
|------|------|
| 外设/模块 | TFT LCD 彩屏（ILI9320 或 SSD1289 控制器，自带 GRAM）、触摸屏控制器（XPT2046，兼容 ADS7843/ADS7846/AK4182/TSC2046）、FSMC |
| 接口/总线 | FSMC Bank1 第4区（NOR/SRAM 控制器，NOR FLASH 控制器），16 位数据总线；触摸芯片走 SPI2（GPIO 模拟） |
| 关键引脚 | 使用 FSMC_D0~FSMC_D15 共16根数据线；FSMC 地址线只用 FSMC_A0 连接 TFT 的 RS 信号（选择命令/数据）；CS 接 FSMC_NE4；另有 WR、RD、RST、BL 控制信号线 |
| 时钟使能 | 手册未明确给出 RCC 宏名（原文：LCD_CtrlLinesConfig() 初始化管脚时钟和 GPIO 功能，LCD_FSMCConfig() 配置 FSMC 总线接口；具体哪些管脚见 TFT 原理图） |
| 关键 API / 寄存器 | ili9320_Initializtion()，ili9320_Clear()，ili9320_SetCursor()，LCD_WriteReg()，LCD_X_Init()，LCD_CtrlLinesConfig()，LCD_FSMCConfig()，LCD_WriteRAM_Prepare()，FSMC_NORSRAMInit()，FSMC_NORSRAMCmd()；结构体 FSMC_NORSRAMInitTypeDef、FSMC_NORSRAMTimingInitTypeDef、LCD_TypeDef；寄存器 FSMC_BCRx、FSMC_BTRx、FSMC_BWTRx、LCD_REG、LCD_RAM；LCD 控制器命令 00h/03h/07h/20h/21h/22h/R50~R53；宏 LCD_BASE ((u32)(0x60000000 | 0x0C000000))、LCD_Bank1_NORSRAM4、FSMC_MemoryType_SRAM、FSMC_MemoryDataWidth_16b、FSMC_WriteOperation_Enable、FSMC_ExtendedMode_Enable、FSMC_DataAddressMux_Disable |
| 初始化步骤 | 1）初始化 STM32 与彩屏模块相连的 IO 管脚；2）初始化彩屏模块（复位 TFT → 驱动 IC 初始化代码 → 复位所有寄存器 → 开启显示 → 显存清 0 → 开始显示）；3）LCD_X_Init() 完成 LCD 与 CPU 管脚初始化，含 LCD_CtrlLinesConfig() 配置 LCD 控制管脚、LCD_FSMCConfig() 配置 FSMC 总线接口；4）读 0x0000 指令读取液晶屏 ID 型号（9320/SSD1289），按型号初始化；5）ili9320_Clear() 逐点写 GRAM 填色（320*240=76800 个点） |
| 常见坑 / 注意 | TFT 通过 RS 决定传的是数据还是命令，RS 接 FSMC_A0：LCD->LCD_REG 地址 0x6C00,0000（A0=0 写命令），LCD->LCD_RAM 地址 0x6C00,0001（A0=1 写数据）；TFT 不需要 FSMC 地址线（A0~A18）；ILI9320 用 16 位控制模式，像素 R:G:B=5:6:5（绿色多 1 位因人眼对绿更敏感），红色 0xF800、蓝色 0x001F、白色 0xFFFF、黑色 0x0000；ILI9320 显存总大小 172800（240*320*18/8）字节；不同液晶控制器入口模式位（I/D0、I/D1、AM）不通用，9341 与 9320 完全不通用，具体参考液晶屏手册；00h 写操作设置 OSC 位为 1 开启内部振荡器后至少等 10ms 时钟稳定 |
| 依赖前置 | FSMC 相关知识（外部 SRAM/存储器接口）；开发板 3.2 寸（或 2.8 寸）TFT 屏；下载方式见 JLINK / 串口 / MDK 在线调试章节 |

**一句话作用**：以 ILI9320 为例讲解 FSMC 驱动 TFT 彩屏的完整流程（初始化 IO → 初始化彩屏模块 → 初始化 FSMC），通过 ili9320_Clear(Red) 把整屏 76800 个点填充为红色（0xF800）。

### 7.47 TFT触摸屏实验（p.648-654）

| 字段 | 内容 |
|------|------|
| 外设/模块 | TFT LCD 彩屏（显示）+ 触摸屏控制器 XPT2046（兼容 ADS7843 等，4 线电阻式，12 位分辨率、125KHz 转换速率、逐次逼近型 A/D） |
| 接口/总线 | 触摸芯片走 SPI2 总线（原文一处称"借助 SPI1 总线"、软件设计处称"SPI2 总线"，且 STM32F103 通过 GPIO 模拟 SPI 接口方式访问）；LCD 显示走 FSMC（见 7.36） |
| 关键引脚 | 触摸中断引脚 PG7（连到 EXTI9_5 中断线）；X+、X-、Y+、Y- 连接到 LCD 触摸屏；ADS7843 的片选 CS 及中断管脚由代码配置（原文未给出具体 GPIO 号） |
| 时钟使能 | 手册未明确给出 RCC 宏名（原文只列初始化函数与宏定义截图） |
| 关键 API / 寄存器 | ADS7843_Init()，ARMJISHU_TouchScreen_ADS7843()，EXTI9_5_IRQHandler()，Delay_ARMJISHU()，DrawPicture_Center()；文件 stm32f10x_it.c、picture.h |
| 初始化步骤 | 1）初始化 TFT LCD 显示（见 7.36）；2）ADS7843 芯片初始化（配置片选 CS 与中断管脚）；3）配置 EXTI 中断线（PG7 映射到 EXTI9_5）；4）在 EXTI9_5_IRQHandler() 中响应触摸中断并调 ARMJISHU_TouchScreen_ADS7843()；5）读取采样数据（4 次采样）并 A/D 转换成显示坐标 |
| 常见坑 / 注意 | 无触摸时 MOSFET ① ② 开、③ 关，中断引脚经上拉电阻输出高；有触摸时 ① ③ 开、② 关，中断引脚经 ③ 接地输出低，向处理器发中断请求；Delay_ARMJISHU() 延时中对中断引脚判断，若触摸在延时过程中响应（若在刷新图片过程中用中断响应可能导致图片混乱）；不同触摸芯片（ADS7843/ADS7846/AK4182/XPT2046/TSC2046）驱动基本一致；中断说明参考《【中文】STM32F系列…参考手册 V10_1.pdf》第137页 |
